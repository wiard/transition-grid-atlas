# KTA Lean / Mathlib Companions

Deze map bevat Lean/mathlib companion-bestanden voor de formele auditlogica rond KTA-figuren.

Deze bestanden bewijzen niet de fysica zelf. Ze leggen governance- en auditrelaties vast, zoals:

- fixed-grid invariantie
- reversibility als metadata
- tie-breaker logica
- not_cross_mode_comparable voor verschillende objective-schalen

Controleer lokaal binnen een geschikt Lake/mathlib project.
